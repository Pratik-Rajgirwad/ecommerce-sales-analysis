# ecommerce-sales-analysis
E-Commerce Sales & Customer Analysis using SQL and Python Pandas



## Project Overview

This project analyzes e-commerce sales, customer, order, and product data using SQL and Python Pandas.

The objective is to understand sales performance, customer spending, product performance, geographic patterns, order status, and monthly revenue trends through data analysis and visualization.

## Tools & Technologies

- SQL / MySQL – Data querying, joins, aggregations, and business analysis
- Python – Data analysis
- Pandas – Data cleaning, transformation, merging, and analysis
- Matplotlib – Data visualization
- Jupyter Notebook – Python analysis environment

## Dataset

The project uses the 'E-Commerce Sales & Customer Analytics Dataset' from Kaggle.

The analysis is based on four relational datasets:

- `customers.csv` – Customer information
- `products.csv` – Product information
- `orders.csv` – Order information
- `order_items.csv` – Products and quantities associated with each order

### Dataset Size

| Dataset | Records |
|---|---:|
| Customers | 300 |
| Products | 50 |
| Orders | 1,000 |
| Order Items | 2,000 |
